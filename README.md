# Paradise Nursery

Paradise Nursery is an online plant shop built with React and Redux Toolkit.
Users can browse houseplants by category, add them to a shopping cart,
adjust quantities, remove items, and see the cart total update live.

## Features
- Landing page with company name, background image and "Get Started" button
- Product listing with 3 categories (6 plants each)
- "Add to Cart" buttons that disable once the plant is added
- Navbar with Home, Plants and Cart (live item count)
- Cart page with per-item subtotal, overall total, +/- quantity, delete,
  Checkout ("Coming Soon") and Continue Shopping

## Run locally
```
npm install
npm run dev
```
